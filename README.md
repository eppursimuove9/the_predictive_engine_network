# The Predictive Engine — Advisory Network

Página estática (un solo `index.html`) con las oportunidades de las redes de expertos.

## Cómo actualizarla
1. Edita `index.html`.
2. `git add . && git commit -m "Update offers" && git push`
3. Vercel despliega solo.

No necesita build ni dependencias. En Vercel: Framework Preset "Other", sin Build Command.
